## 如何使用本教程

1. **按顺序阅读**：文档之间有依赖关系，建议从 00 开始按编号阅读
2. **动手实践**：每篇都有代码示例，建议边读边写
3. **验证学习**：每篇末尾有验证方法，确认理解后再进入下一篇
4. **回查参考**：遇到问题时可以回查具体文档

## 技术栈速查

| 技术 | 用途 | 学习难度 |
|------|------|---------|
| Python 3.11+ | 主语言（async/await） | ★★☆ |
| CrewAI | Agent 编排框架 | ★★★ |
| Pydantic | 配置校验与数据模型 | ★★☆ |
| asyncio | 异步并发 | ★★★ |
| Docker | 沙箱隔离 | ★★☆ |
| PostgreSQL + pgvector | 向量记忆搜索 | ★★☆ |
| Langfuse | 可观测性平台 | ★★☆ |
| MCP 协议 | 工具调用标准 | ★★★ |
